# 043 3D 训练数据：魔法图书馆角落场景（书架 + 书桌 + 烛台）多视角标注

040 魔法图书馆角落场景的 8 组资产拼成室内场景的多视角训练数据：
4 个视角的逐物体包围盒 + 关键点，全部由相机真实投影算出，不编造。

## 标注对象（8 组，2084 面）

- `lowpoly_bookshelf`（高书架，750 面）：后墙 5 层书架（2.5 宽 × 2.35 高）+ 111 本书 + 3 本平放叠书 + 梯子旁 2 本地面散书
- `lowpoly_low_shelf`（矮书架，404 面）：左墙 2 层书架 + 38 本书 + 顶上地球仪（蓝球 + 金色子午环）
- `lowpoly_ladder`（图书馆梯子，48 面）：两根立柱 + 6 根横档，向书架倾斜 17.7°
- `lowpoly_desk`（书桌，270 面）：1.7×0.90 台面 + 4 腿 + 抽屉（黄铜拉手）+ 翻开的法术书 + 墨水瓶 + 羽毛笔 + 3 本叠书 + 横放羊皮卷轴
- `lowpoly_candelabra`（桌上三臂烛台，270 面）：黄铜底座 + 3 支蜡烛 + 火焰
- `lowpoly_floor_candle`（落地烛台，216 面）：黄铜底座 + 1.28 高立柱 + 托盘 + 3 支蜡烛 + 火焰
- `lowpoly_chair`（木椅，48 面）：座面 + 4 腿 + 靠背
- `lowpoly_star_chart`（星图挂画，78 面）：深蓝画布 + 金月 + 5 颗金星
- 标注组总面数 2084；整场景实测 2199 面（含墙体 / 地板 / 地毯 / 地面；
  040 原记录 2198 面不含 Ground 平面，本轮含 Ground 故多 1 面）

## 布局（米，沿用 040，不重新摆位）

- 040 场景原样从 .blend 提取（除 Camera 外全部物体，包括三点灯光与落地烛台点光源）
- 高书架在后墙（x -1.6..0.9，y=1.95，5 层，111 本书）；矮书架在左墙（x=-1.95，y -0.6..1.4，2 层，38 本书），地球仪在矮书架顶上
- 梯子靠在高书架上（倾斜 17.7°）；书桌在 (1.05, 0.55)，台面 z=0.78
- 桌上三臂烛台在书桌右侧；落地烛台在 (-1.55, 0.75)，暖色点光源 180W
- 星图挂画在书桌上方后墙 (1.70, y=2.03, z=1.65)；地毯 + 木椅在书桌前方
- 后墙（y=+2.2）与左墙（x=-2.2）为背景，故无后视视角
